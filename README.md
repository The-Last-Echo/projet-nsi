# Projet NSI

Projet de groupe réalisé en Python dans le cadre de la spécialité NSI.

## Objectifs

- Développer un jeu en console en Python.
- Travailler à plusieurs avec Git et GitHub.
- Documenter les choix techniques et l'organisation du projet.

## Prérequis

- Python 3 (à préciser).
- Git.

## Lancer le projet

Les instructions de lancement seront ajoutées lorsque la structure et le point d'entrée du programme auront été définis.

## Organisation

- `src/` : code source (à mettre en place).
- `tests/` : tests automatisés (à mettre en place).
- `docs/` : documentation du projet et du workflow.
