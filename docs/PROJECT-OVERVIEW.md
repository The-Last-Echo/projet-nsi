# Présentation du projet

## Contexte

Projet de groupe réalisé dans le cadre de la spécialité NSI, avec Python.

## Concept

Le projet prendra la forme d'un jeu en console. Les règles précises, les objectifs, les mécaniques et les conditions de victoire/défaite restent à définir et à documenter collectivement.

## Choix techniques connus

- Langage : Python.
- Interface : console/terminal.
- Représentation de la grille envisagée : liste de listes (à confirmer dans la conception).
- Gestion du code : Git et GitHub.
